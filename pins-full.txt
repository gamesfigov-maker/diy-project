ПОЛНЫЙ СПИСОК ПИНОВ — ESP32-S3 + Bruce (плата smoochiee-board)
================================================================
Всё сверено с конфигом прошивки: boards/smoochiee-board/pins_arduino.h
и boards/smoochiee-board/smoochiee-board.ini.

Формат: вывод модуля -> пин платы ESP32-S3.


───────────────────────────────────────────────
1. ПИТАНИЕ ПЛАТЫ
───────────────────────────────────────────────
3V3   (их два пина) -> плюс 3.3 В для дисплея, CC1101, NRF24, PN532, GPS, IR
5V                 -> питание от DC-DC 5 В (или от USB)
GND   (их три пина) -> общий минус, всё соединяется вместе
RST                -> не трогаем, это кнопка RESET на плате
GPIO19 и GPIO20    -> USB (D- и D+), НЕ занимать
GPIO26…37          -> заняты флешем и PSRAM, недоступны


───────────────────────────────────────────────
2. ДИСПЛЕЙ  (IPS 1.14" 135x240, ST7789V, 4-wire SPI)
───────────────────────────────────────────────
GND -> GND
VCC -> 3V3          (только 3.3 В! 5 В сгорит)
SCL -> GPIO18       (SCK)
SDA -> GPIO17       (MOSI)
RES -> GPIO16
DC  -> GPIO15
CS  -> GPIO7
BLK -> GPIO6        (подсветка)
В прошивке: 135x240, SPI 20 МГц, смещение кадра 52/40, инверсия выключена.


───────────────────────────────────────────────
3. КНОПКИ  (5 шт, активны на GND, подтяжки внутри)
───────────────────────────────────────────────
Каждая кнопка: один вывод -> GPIO, второй вывод -> GND
UP    -> GPIO41
DOWN  -> GPIO40
LEFT  -> GPIO39
RIGHT -> GPIO38
OK    -> GPIO0      (это кнопка BOOT на плате)
Выключение устройства: LEFT + RIGHT вместе ~3 секунды.
Esc/назад: LEFT + RIGHT.


───────────────────────────────────────────────
4. SD-КАРТА  (6-пиновый microSD адаптер, SPI)
───────────────────────────────────────────────
GND  -> GND
VCC  -> 3V3         (только 3.3 В!)
CS   -> GPIO3
MOSI -> GPIO17      (общий провод с дисплеем)
SCK  -> GPIO18      (общий провод с дисплеем)
MISO -> GPIO8
ВАЖНО: у дисплея CS = GPIO7, у карты CS = GPIO3 — разные.
SCK/MOSI/MISO у дисплея и карты общие — так задумано.


───────────────────────────────────────────────
5. CC1101  (433 МГц, вторая шина HSPI)
───────────────────────────────────────────────
VCC  -> 3V3
GND  -> GND
SCK  -> GPIO13
MOSI -> GPIO12
MISO -> GPIO11
CSN  -> GPIO46
GDO0 -> GPIO9
GDO2 -> GPIO10
Конденсатор у модуля: 100 нФ керамика (или 100 мкФ) — обязательно.


───────────────────────────────────────────────
6. NRF24L01+  (2.4 ГГц, та же шина HSPI)
───────────────────────────────────────────────
VCC  -> 3V3
GND  -> GND
SCK  -> GPIO13      (общий с CC1101)
MOSI -> GPIO12      (общий с CC1101)
MISO -> GPIO11      (общий с CC1101)
CSN  -> GPIO14
CE   -> GPIO21
Конденсатор 100 нФ прямо на модуль — ОБЯЗАТЕЛЬНО, иначе не работает.


───────────────────────────────────────────────
7. PN532  (RFID/NFC, I2C)
───────────────────────────────────────────────
VCC -> 3V3
GND -> GND
SDA -> GPIO47
SCL -> GPIO48
Переключатели на модуле: I2C (1 = ON, 2 = OFF).
Подтяжки 4.7 кОм обычно уже стоят на модуле.


───────────────────────────────────────────────
8. GPS NEO-6M  (UART)
───────────────────────────────────────────────
VCC        -> 3V3
GND        -> GND
TX модуля  -> GPIO2     (это RX платы)
RX модуля  -> GPIO1     (это TX платы)
Скорость 9600. Пины 1 и 2 заняты GPS — их же хочет микрофон.


───────────────────────────────────────────────
9. IR  (пульт)
───────────────────────────────────────────────
VCC             -> 3V3
GND             -> GND
OUT приёмника   -> GPIO4   (TSOP38438, 38 кГц)
LED передатчик  -> GPIO5   (модуль KY-005)
Полезно: 100 нФ + 100 Ом в питание приёмника.


───────────────────────────────────────────────
10. RGB LED WS2812B
───────────────────────────────────────────────
VCC -> 5V
GND -> GND
DIN -> GPIO45
В прошивке 16 светодиодов. Ток до ~1 А на 5 В — проверь DC-DC.
Полезно: 300–500 Ом в линию данных, 100 нФ на питание.


───────────────────────────────────────────────
11. ЗУММЕР
───────────────────────────────────────────────
+ -> GPIO44     (на плате этот пин подписан RX)
- -> GND


───────────────────────────────────────────────
12. СВОДНАЯ ТАБЛИЦА: GPIO -> ЧТО ПОДКЛЮЧЕНО
───────────────────────────────────────────────
GPIO0   кнопка OK (BOOT)
GPIO1   GPS: TX платы -> RX модуля   (UART1 TX)
GPIO2   GPS: RX платы <- TX модуля   (UART1 RX)
GPIO3   SD-карта CS  (он же SS по умолчанию)
GPIO4   IR приёмник (RXLED)
GPIO5   IR светодиод (TXLED)
GPIO6   дисплей BLK (подсветка)
GPIO7   дисплей CS
GPIO8   SD MISO  (и TFT_MISO, дисплею не нужен)
GPIO9   CC1101 GDO0
GPIO10  CC1101 GDO2
GPIO11  HSPI MISO (CC1101 + NRF24)
GPIO12  HSPI MOSI (CC1101 + NRF24)
GPIO13  HSPI SCK  (CC1101 + NRF24)
GPIO14  NRF24 CSN
GPIO15  дисплей DC
GPIO16  дисплей RES
GPIO17  дисплей SDA/MOSI + SD MOSI
GPIO18  дисплей SCL/SCK  + SD SCK
GPIO19  USB D-      НЕ ЗАНИМАТЬ
GPIO20  USB D+      НЕ ЗАНИМАТЬ
GPIO21  NRF24 CE
GPIO26–37  флеш и PSRAM, недоступны
GPIO38  кнопка RIGHT
GPIO39  кнопка LEFT
GPIO40  кнопка DOWN
GPIO41  кнопка UP
GPIO43  SPI_SS — зарезервирован, не используется
GPIO44  зуммер (пин подписан RX)
GPIO45  RGB LED (WS2812B, 16 шт)
GPIO46  CC1101 CSN
GPIO47  I2C SDA: PN532 + Grove SDA
GPIO48  I2C SCL: PN532 + Grove SCL


───────────────────────────────────────────────
13. ЕСТЬ В ПРОШИВКЕ, НО ТОЛЬКО ДЛЯ ЗАВОДСКОЙ ПЛАТЫ
───────────────────────────────────────────────
Это НЕ подключать на DIY-сборке:
- BQ25896 (зарядный чип, I2C) + USE_BOOST — процент батареи работать не будет;
- расширитель AW9523 (IO_EXPANDER) — I/O расширитель на заводской плате;
- микрофон INMP441: BCLK=GPIO1, WS=GPIO2, DIN=GPIO10 — конфликтует
  с GPS (пины 1 и 2) и CC1101 GDO2 (пин 10), поэтому одно ИЛИ другое;
- вибромотор (на расширителе).
Именно из-за отсутствия PMIC и расширителя в логе сыпятся
ошибки "i2cWrite ESP_ERR_INVALID_STATE" — это нормально.


───────────────────────────────────────────────
14. ЧЕГО НЕ ДЕЛАТЬ
───────────────────────────────────────────────
1. Не подавать 5 В на VCC дисплея, SD, CC1101, NRF24, PN532, GPS, IR.
2. Не путать CS дисплея (7) и CS карты (3).
3. Не занимать GPIO19 и GPIO20.
4. Не перепутать полярность электролитического конденсатора:
   плюс (длинная ножка) к +3V3, минус (полоска) к GND.


───────────────────────────────────────────────
15. ПРОВОДА
───────────────────────────────────────────────
Провод с жилой 0.3 мм (сечение ~0.07 мм², это AWG 28), длина 8 см:
  - сигналы (SPI, I2C, UART, кнопки) — подходит полностью;
  - питание 3V3 платы, дисплея, кнопок — подходит (токи до 0.3 А);
  - 5 В на RGB-ленту — НЕ подходит: там до 1 А, нужен провод
    толще (0.5–0.75 мм², это жила ~0.8–1.0 мм).
Длина 8 см — хорошо, это как раз короткий провод для SPI.
Ставь провода покороче и по возможности веди рядом с землёй.
Если дисплей начнёт «сыпаться» — первым делом укороти провод GND.
