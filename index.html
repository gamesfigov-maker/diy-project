05 Руководство

Что умеет Bruce

Bruce — это мощная прошивка для ESP32 с десятками функций: от Wi-Fi анализа до работы с радиосигналами.

Wi-Fi

Подключение к сетям, анализ, сканирование хостов, TelNet, SSH, Evil Portal, RAW Sniffer, Wardriving.

Bluetooth LE

BLE Scan, Bad BLE, BLE-клавиатура, спам-режимы для iOS, Windows, Samsung, Android.

RF / Sub-GHz

Сканирование и повтор передачи радиосигналов, работа с CC1101, анализ 433/868/915 МГц.

RFID / NFC

Чтение и запись меток, эмуляция карт, работа с PN532. Mifare, FeliCa, ISO14443.

Инфракрасный порт

Приём и передача ИК-сигналов, TV-B-Gone, сохранение и повтор команд.

BadUSB / HID

Эмуляция клавиатуры через USB и BLE. Ducky-скрипты. Только ESP32-S3.

JavaScript

Встроенный интерпретатор MicroQuickJS. Свои приложения и скрипты.

Настройки

Яркость, звук, LED-эффекты, темы, InstaBoot, выбор стартового приложения.
