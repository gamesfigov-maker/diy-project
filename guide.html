Что умеет Bruce

Bruce — мощная прошивка для ESP32-S3 с десятками функций: от Wi-Fi анализа до работы с радиосигналами. Здесь описано всё, что доступно в меню устройства.

Wi-Fi

Беспроводные сети · 2,4 ГГц

Подключение к Wi-Fi сетям, анализ эфира и работа с сетевыми протоколами. Требуется подключение к сети или режим точки доступа.

Connect to WiFi

Подключение к выбранной сети. Открывает доступ к сетевым функциям — TelNet, SSH, TCP Listener, ARP Poisoning.

WiFi AP

Устройство создаёт собственную точку доступа. К ней могут подключаться телефоны и компьютеры.

Scan Hosts

Сканирование сети на предмет подключённых устройств. Показывает IP и MAC-адреса.

Beacon Spam тест

Создание множества фейковых точек доступа. Только для тестирования собственных сетей.

Evil Portal обучение

Создание фейковой страницы входа в Wi-Fi. Только для обучения и тестирования на своём оборудовании.

Важно: работа с чужими Wi-Fi сетями без разрешения владельца запрещена законом. Все функции этого раздела предназначены для тестирования вашей собственной инфраструктуры.

Bluetooth LE

Bluetooth 5.0 · Low Energy

Работа с Bluetooth-устройствами вокруг: сканирование, эмуляция, спам-режимы.

BLE Scan

Поиск Bluetooth-устройств рядом. Показывает имя, MAC-адрес, уровень сигнала (RSSI).

Bad BLE / BLE Keyboard

Эмуляция Bluetooth-клавиатуры. Устройство подключается к телефону или компьютеру как клавиатура и выполняет Ducky-скрипты.

iOS / Windows / Samsung / Android Spam

Отправка множества запросов на сопряжение. На устройствах рядом появляются всплывающие уведомления. Только для тестирования своего оборудования.

RF / Sub-GHz

Радиочастоты · CC1101

Работа с радиосигналами через модуль CC1101. Поддерживаемые частоты: 300–348, 387–464, 779–928 МГц.

Scan / Copy

Сканирование эфира и запись сигнала. Сохранение в файл .sub для последующего воспроизведения.

Custom SubGhz

Ручная настройка частоты, модуляции, скорости передачи. Работа с нестандартными сигналами.

TV-B-Gone

Отправка ИК-кодов выключения для популярных моделей телевизоров. Только для собственных устройств.

RFID / NFC

13,56 МГц · PN532

Работа с NFC-метками через модуль PN532. Частота 13,56 МГц, поддержка Mifare, FeliCa, ISO14443A/B.

Read Tag

Чтение информации с NFC-метки: UID, тип карты, данные в секторах памяти.

Write Tag

Запись данных на метку. Поддерживаются карты Mifare Classic и Ultralight.

Emulate Tag

Эмуляция NFC-карты. Устройство притворяется меткой перед считывателем — для тестирования своих систем доступа.

Инфракрасный порт

38 кГц приём · ~940 нм передача

Приём и передача инфракрасных сигналов. Работает как универсальный пульт для бытовой техники.

IR Read

Приём сигнала от ИК-пульта. Сохранение в файл для последующей отправки.

IR Send

Отправка сохранённого ИК-сигнала. Управление телевизором, кондиционером, вентилятором.

BadUSB / HID

Эмуляция клавиатуры · только ESP32-S3

Эмуляция клавиатуры через USB или Bluetooth. Устройство подключается к телефону или компьютеру как обычная клавиатура и выполняет Ducky-скрипты.

Доступно только на ESP32-S3. ESP32 (классический) не поддерживает USB-HID и Bluetooth-клавиатуру. Наш набор использует ESP32-S3.

BadUSB

Запуск Ducky-скриптов. Устройство подключается как USB-клавиатура и выполняет скрипт на целевом компьютере.

Keyboard Layout

Выбор раскладки клавиатуры (RU, EN, DE и др.) и задержки между нажатиями клавиш.

Важно: BadUSB предназначен для тестирования собственных систем безопасности. Использование на чужих устройствах без разрешения владельца запрещено законом.

JavaScript

MicroQuickJS интерпретатор

Встроенный интерпретатор MicroQuickJS позволяет создавать собственные приложения прямо на устройстве. Не нужен компьютер — только дисплей, кнопки и код.

Scripts

Запуск скриптов из папки /BruceJS на SD-карте или внутренней памяти.

GPIO API

Управление пинами: digitalWrite, analogWrite, pinMode. Прямой доступ к железу ESP32 из JS.

WiFi / BLE API

Работа с Wi-Fi и Bluetooth из скриптов. Создание собственных автоматизаций и приложений.

WebUI

Управление из браузера

Управление устройством через браузер. Подключитесь к ESP32 по Wi-Fi и откройте веб-интерфейс. Пароль по умолчанию: admin / bruce.

WebUI

Полноценный веб-интерфейс: запуск функций, настройки, мониторинг состояния устройства.

File Manager

Загрузка и скачивание файлов на SD-карту или внутреннюю память LittleFS через браузер.

Настройки

Персонализация устройства

Bruce позволяет полностью настроить устройство под себя: экран, звук, LED-индикация, поведение при загрузке.

Display & UI

  • Яркость экрана
  • Время до затемнения
  • Ориентация экрана
  • Цветовая схема и темы

Audio

Включение/выключение звука, регулировка громкости для Cardputer и аналогичных устройств со звуком.

System

  • InstaBoot — быстрая загрузка
  • Выбор стартового приложения
  • Скрытие ненужных пунктов меню
  • Настройка времени и даты

Power

Настройки питания, информация о батарее, режим сна. Для устройств с аккумулятором.
